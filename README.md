# 🌍 Low Poly World

A simple browser-based low-poly 3D exploration game built with [Three.js](https://threejs.org/).

## Features

- Procedural low-poly terrain
- Scattered trees, rocks, flowers, and clouds
- Third-person camera with WASD movement
- Run (Shift), Jump (Space), Look around (Mouse)

## How to Play

Just open `index.html` in any modern browser — no build step needed.

## Controls

| Key | Action |
|-----|--------|
| W / ↑ | Walk forward |
| A / ← | Walk left |
| S / ↓ | Walk backward |
| D / → | Walk right |
| Shift | Run |
| Space | Jump |
| Mouse | Look around (click to lock cursor) |

Built with Hermes Agent.
